# Lenovo TB350 Open Source Upgrade Project

Community research and documentation for running open-source Android system images on the Lenovo Tab P11 (2nd Gen), models TB350FU and TB350XU.

The project does not distribute Lenovo firmware or proprietary binaries. Device modifications can erase data or make a tablet unbootable; all procedures should be reviewed and tested before use.

Substantive documentation is developed through pull requests.
